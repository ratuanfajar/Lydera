# Log temuan

Temuan dari uji perilaku nyata (stack lokal: `docker-compose.dev.yml` + API + worker, LLM Azure nyata). Tingkat: tinggi (data/keamanan/salah fungsi), sedang (kualitas atau kebenaran sebagian), rendah (kebersihan/info). Status: terbuka, dikerjakan (fase), selesai, ditolak.

Aturan lingkup (diperbarui): pemilik pekerjaan ini menangani ai-services (Annoter, Quizzer, Evaluaizer, Clarifier) dan perubahan backend yang menjadi konsekuensinya (rename domain/prefix API, domain evaluaizer, migrasi untuk fitur AI). Temuan proses bisnis backend di luar itu semula hanya dicatat sebagai `bypass (ranah BE)`. Pada 2026-10-27 user meminta bug logika dan otorisasi yang jelas salah (F-001, F-012, F-018 sampai F-023) diperbaiki agar sesuai logika: guru hanya mengelola kuis/soal miliknya, siswa hanya mengerjakan kuis yang dipublish di kelas tempat ia terdaftar. Sisa temuan non-AI tetap `bypass`.

## Baseline (sebelum perubahan), 2026-10-27

Data uji: 1 modul "Lingkaran", 1 bab (244 blok dari `annotated.json` bab2-xi: 47 heading, 82 teks, 109 gambar, 5 rumus, 1 tabel), 47 chunk embedding, 1 kuis (2 LOTS + 1 HOTS), 1 siswa menjawab 3 soal.
